# 데이터/API 협의 진행표

기준일: 2026-11-22 · 백엔드 v1.5.0

프론트·AI의 이전 회신과 현재 코드를 대조한 진행 기록이다. ‘구현’은 백엔드의 모의 시험 기준이며 새로 최종 동의를 받았다는 뜻은 아니다.

용도는 노션에 협의 진행 상황을 기록하는 것이다. ‘현재 반영’은 백엔드가 준비한 내용, ‘다음에 받을 결과’는 팀원과 확인하거나 시험해야 할 내용이다. 팀에 보낼 새로운 요청문이나 최종 합의서는 아니다.

| 대상 | 현재 반영 | 다음에 받을 결과 |
|---|---|---|
| 프론트 | 전화번호 null 포함, 본인 복약 CRUD, 관리자 전체 상태·사고·실시간 규격, 로그인 준비 | 화면 호출 결과, 요일·음성 UI, 관찰 기간·초기 무판단 표시, 상세 화면 딥링크, 푸시 제공자 |
| AI | 위험·센서 근거 필드, 1차 의심/최종/실패 처리 제안, 불가 결과를 안전으로 바꾸지 않는 규칙 | 실제 출력 JSON, 위험 단계와 신뢰도의 의미·단위, 최종 취소와 camera false/UNKNOWN의 차이, 관찰 통계 |
| 게이트웨이·하드웨어 | HTTP 위험·활동·하트비트·패턴 수신, 명령 조회·ACK | 실제 장치 ID와 대상 매핑, 전송 주체·시각·재시도·빈도, 센서 단위, 실제 스피커 ACK |
| 공동 | 현재 OpenAPI·예시·ERD 정리 | 버전별 최종 합의, 접속 가능한 서버 주소, 실제 기기 연결 시험 |

1차 프론트 시험 순서: 어르신 목록 → 현재 상태 → 복약 일정 조회. 현재 담당자의 준비 상태는 별도 확인하며 실제 연동 결과를 추정해서 적지 않는다.

현재 미구현·미검증: MQTT 수신, 실제 푸시 전송, 실제 스피커 출력, 실제 AI 호출·센서 수신, 전체 통합, 운영 부하·응답시간 시험. 개인정보·영상 보관·삭제 기간도 공동 결정이 필요하다.
