## 명세·설계 정합성

- 실제 앱에서 25개 경로 / 27개 HTTP 동작의 OpenAPI를 생성했다.
- 각 HTTP 동작의 성공 요청·응답 예시 27개를 메모리 DB의 실제 호출 결과로 저장했다.
- 실제 DDL에서 18개 테이블·FK를 읽어 데이터 사전·Mermaid ERD·SVG 관계도를 만들었다.
- TypeScript schema 자료형은 같은 OpenAPI에서 생성했다.
- 구성도·ERD는 PNG로 변환해 글자·박스·관계선의 표시를 확인했다. SVG 원본으로 확대해서 볼 수 있다.

## 실행 한계와 미검증 항목

이 도구 실행 환경에서는 장기 실행 서버의 loopback 접속이 실패했다. Node 환경의 확인 결과는 `connect EACCES 127.0.0.1:8001`이며, 셸·내장 브라우저에서도 로컬 접속이 실패하거나 시간 초과됐다. 별도 Edge 자동 시험은 브라우저 프로세스 초기화에 실패했다. **따라서 브라우저의 버튼 조작을 통한 실제 화면 E2E, LAN의 다른 기기 접속, 인터넷 공개 URL 배포는 완료됐다고 주장하지 않는다.**

제공된 start.ps1 또는 README의 Python 명령으로 일반 PC에서 실행한 뒤 README의 화면 확인 순서를 수행하면 된다. 서버 코드의 REST·WebSocket·DB 통합 경로는 위 TestClient 시험으로 검증했다. Docker 빌드·실행, 실제 모바일·Expo/FCM·스피커, 1초 이내 지연 목표·부하시험은 이번 결과에 포함하지 않는다.

테스트 중 Starlette가 httpx 기반 TestClient의 향후 사용 중단 경고 1건을 출력했다. 테스트 실패는 아니며 검증한 라이브러리 버전은 requirements-lock.txt에 고정했다.

## 재현

프로젝트 루트에서:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe -m pytest tests -q
.\.venv\Scripts\python.exe tools/export_contract.py
```

네트워크·사용자 권한 제약으로 시스템 임시 디렉터리를 쓸 수 없다면 pytest에 `--basetemp=./test-temp`를 추가한다. 테스트 전용 경로를 지정해야 하며 pytest는 그 임시 경로를 관리·정리한다.
