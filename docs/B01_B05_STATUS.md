완료 표시는 위 범위 기준이다. 원래 계획 날짜는 유지하고, 먼저 만든 후속 기능은 본문에 ‘선행 구현·모의 검증’으로 기록한다. B06 이후의 실데이터 연동과 공동 시험까지 완료한 것으로 표시하지 않는다.

현재 기준 수치: SQLite 21개 테이블·141개 열·33개 FK, HTTP 34개 경로·36개 작업, 일반 요청·응답 예시 36개, WebSocket 2개, 자동시험 87개 통과. 비밀번호 인증과 카메라 처리 선행 작업에 필요한 테이블도 현재 설계에 포함했다.

아래 B01~B05 본문을 같은 이름의 노션 작업 페이지에 각각 붙여넣는다. ‘첨부자료’의 파일은 ZIP을 풀어서 직접 올린다. PC 파일 경로나 localhost 주소를 붙여넣는 것만으로 팀원이 파일을 열 수 있게 되지는 않는다.
