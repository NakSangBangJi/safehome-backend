# Git 공유 전 검사

검사일: 2026-11-24 · 서버 버전: 1.5.0

전체 자동시험을 시험용 DB로 다시 실행하여 **87개 통과, 경고 1개**를 확인했습니다. 경고는 Starlette TestClient의 httpx 사용 방식에 대한 사용 중단 예고입니다. 실제 센서·AI·프론트 통합 시험, 실제 휴대폰 푸시·스피커 출력 시험을 뜻하지 않습니다.

공유 범위는 서버 코드, 시험 코드, 프론트 호출 예시, 최신 API 문서, ERD, DB 정의서와 모의 검증 증빙입니다. 실행 DB와 백업 DB, 연습용 비밀번호 파일, 가상환경, 캐시, 환경변수 파일, 개인 키는 Git 추적 대상에서 제외했습니다.

최신 전체 ERD 편집 파일은 `docs/latest-drawdb.json`입니다. DB는 21개 테이블, 141개 열, 33개 외래키이며 기존 데이터 구조는 변경하지 않았습니다.

사용자가 실행 중인 서버와 개인 DB를 종료·초기화하지 않았습니다. 팀원은 README 설치 순서대로 실행하여 각자 새 가상 DB를 만들 수 있습니다.
